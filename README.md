# WhatsApp Business Bot

Bot de WhatsApp para pequeños y medianos negocios.

## Funcionalidades
- Respuestas automáticas a consultas frecuentes
- Integración con catálogo de productos
- Tomar pedidos básicos
- Notificaciones de estado

## Arquitectura
- WhatsApp Business API / Twilio
- Python backend
- Base de datos SQLite/PostgreSQL
- Panel web de administración (opcional)

## Casos de uso
- Restaurantes: menú y pedidos
- Tiendas: consulta de stock
- Servicios: turnos y recordatorios
